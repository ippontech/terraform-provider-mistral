# mistral_library (Resource)

Manages a library of the workspace of the standard API key (`api_key`): a knowledge base of documents that the `document_library` tool of a `mistral_agent` searches. Add its documents with `mistral_library_document`, and its access grants with `mistral_library_share`.

-> **Public preview at Mistral.** The Libraries API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This resource is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

## Owner

`owner_type` defaults to `Workspace`: the library is shared with the workspace of the API key. A `User` library is private to its owner, and only an API key with the "Private and shared connectors" connector access scope can create one. The API cannot change the owner: changing `owner_type` replaces the library, which deletes its documents. The `mistral_library_document` resources of the library are then replaced too, and their files uploaded again.

## Documents

Destroying the library deletes its documents. `nb_documents` and `total_size` are read at each refresh: documents uploaded in the same apply as the library show in the next plan, not in the state of that apply.

## Example Usage

```terraform
resource "mistral_library" "support" {
  name        = "support-docs"
  description = "Product documentation the support agent answers from."
}

# The agent searches the library with its document_library tool.
resource "mistral_agent" "support" {
  name  = "support"
  model = "mistral-medium-latest"
  tools = [
    { type = "document_library", library_ids = [mistral_library.support.id] },
  ]
}
```

## Schema

### Required

- `name` (String) The name of the library.

### Optional

- `description` (String) The description of the library.
- `owner_type` (String) Who owns the library: `Workspace` (the default), shared with the workspace of the API key, or `User`, private to its owner. Only an API key with the "Private and shared connectors" connector access scope can create a `User` library. Changing it replaces the library and deletes its documents.

### Read-Only

- `created_at` (String) When the library was created, in RFC 3339 format.
- `id` (String) The library ID, a UUID such as `0197f425-5e85-7353-b8e7-e8b974b9c613`. Give it to the `library_ids` of a `document_library` tool.
- `nb_documents` (Number) The number of documents of the library, as of the last refresh.
- `owner_id` (String) The ID of the workspace or the user that owns the library.
- `total_size` (Number) The total size of the documents of the library, as of the last refresh.
- `updated_at` (String) When the library was last updated, in RFC 3339 format.

## Import

In Terraform 1.12 and later, an `import` block can use the resource identity:

```terraform
import {
  to = mistral_library.support
  identity = {
    id = "0197f425-5e85-7353-b8e7-e8b974b9c613"
  }
}
```
