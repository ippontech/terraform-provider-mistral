# mistral_agent (Resource)

Manages an agent of the workspace of the standard API key (`api_key`): its model, instructions, tools and sampling arguments.

-> **Public preview at Mistral.** The Agents API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This resource is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

## Versions

Every update creates a new version of the agent, which becomes its active version; `version` gives its number, from 0 after the create. The API keeps the previous versions; destroying the resource deletes the agent. To keep conversations on a reviewed version while the agent moves on, point a `mistral_agent_alias` at that version.

A change made in AI Studio also creates a version. The next plan shows it as drift, and the apply writes the configuration back as one more version.

## Defaults

When an argument is left out, the provider sends what the API would fill in: no tools, `tool_choice = "auto"` and every other sampling argument null, an empty `description` and `strict = false` for a function. A field the API leaves null, such as `temperature`, takes the default of the model.

`function.parameters` and `response_format.json_schema.schema` are JSON documents: write them with `jsonencode`. The state keeps the configured text as long as the API returns the same JSON value, whatever its spacing or key order.

## Not managed yet

`guardrails` (moderation settings), `deployment_chat` (the agent in Le Chat) and the `authorization` of a connector tool are not arguments of this resource yet. A change made to them outside Terraform is kept by the next update only if the API keeps a field that the update leaves out, which is not documented.

## Example Usage

```terraform
resource "mistral_agent" "support" {
  name         = "support"
  model        = "mistral-medium-latest"
  description  = "Answers questions on orders."
  instructions = "Answer from the order data only, and say so when it does not cover the question."

  tools = [
    { type = "web_search" },
    {
      type = "function"
      function = {
        name        = "get_order"
        description = "Returns an order by its ID."
        parameters = jsonencode({
          type       = "object"
          properties = { order_id = { type = "string" } }
          required   = ["order_id"]
        })
      }
    },
  ]

  completion_args = {
    temperature = 0.2
  }

  metadata = { team = "support" }
}
```

## Schema

### Required

- `model` (String) The model the agent runs on: a model ID or an alias, such as `mistral-medium-latest`. See the `mistral_model` data source.
- `name` (String) The name of the agent.

### Optional

- `completion_args` (Attributes) The sampling arguments of the agent's responses. A conversation can override them. (see [below for nested schema](#nestedatt--completion_args))
- `description` (String) The description of the agent.
- `handoffs` (List of String) The IDs of the agents this agent can hand a conversation over to.
- `instructions` (String) The instruction prompt the model follows in every conversation with the agent.
- `metadata` (Map of String) Free-form string metadata of the agent. A value set outside Terraform as another JSON type reads as its JSON text.
- `tools` (Attributes List) The tools the agent can use, in order. `type` selects the tool; `function`, `library_ids` and `connector_id` belong to the `function`, `document_library` and `connector` types only. (see [below for nested schema](#nestedatt--tools))
- `version_message` (String) A message describing the version that the next create or update produces. Changing it alone creates a new version.

### Read-Only

- `created_at` (String) When the agent was created, in RFC 3339 format.
- `id` (String) The agent ID, such as `ag_0684fe0e0b98773e8000323fc71a3986`.
- `updated_at` (String) When the agent was last updated, in RFC 3339 format.
- `version` (Number) The active version of the agent: 0 after the create, then one more on each update. Point a `mistral_agent_alias` at it.

### Nested Schema for `completion_args`

Optional:

- `frequency_penalty` (Number) Penalizes tokens by how often they appear in the response, from -2 to 2.
- `max_tokens` (Number) The maximum number of tokens of a response.
- `presence_penalty` (Number) Penalizes tokens that already appear in the response, from -2 to 2.
- `random_seed` (Number) The seed of the random sampling, for reproducible responses.
- `reasoning_effort` (String) The reasoning effort of a reasoning model: `none`, `minimal`, `low`, `medium`, `high` or `xhigh`.
- `response_format` (Attributes) The format of the responses. When null, the agent answers in text. (see [below for nested schema](#nestedatt--completion_args--response_format))
- `stop` (List of String) The sequences that stop the generation.
- `temperature` (Number) The sampling temperature. When null, the model's default applies (see `default_temperature` of `mistral_model`).
- `tool_choice` (String) Whether the model calls tools: `auto` (the default), `none`, `any` or `required`.
- `top_p` (Number) Nucleus sampling: the probability mass of the tokens considered, from 0 to 1.
