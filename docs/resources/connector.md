# mistral_connector (Resource)

Manages a connector of the workspace of the standard API key (`api_key`): an MCP or HTTP server registered with Mistral, whose tools an agent can call through a `connector` tool of a `mistral_agent`.

-> **Public preview at Mistral.** The Connectors API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This resource is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

## Visibility

`visibility` says who can use the connector:

- `private`: its creator only;
- `shared_workspace`: the members of the workspace;
- `shared_org`: the members of the organization. Only organization admins can create and manage these connectors.

The argument is required, although the API defaults to `private`. An API key sees private connectors only when it has the `Private and shared connectors` access scope, and the default scope is `Shared connectors only`: with such a key, a private connector would disappear from Terraform after its creation. Use `shared_workspace` for automation.

The create sends the visibility. A change goes through the share calls of the API, which only take a private connector: from `shared_workspace` to `shared_org`, the provider first makes the connector private, then shares it with the organization. When a connector stops being shared with the workspace or the organization, the API removes the credentials of that scope, except its creator's: the next plan then recreates the `mistral_connector_credential` resources of that scope. Only the creator of the connector can share it with the workspace.

## Updates and replacements

An update sends every argument, so removing an optional argument clears it. Changing `protocol` replaces the connector. The update of an `http` connector takes no system prompt: changing `system_prompt` replaces an `http` connector, and updates an `mcp` one in place. A replacement deletes the connector, and the agents that use it lose its tools until they point at the new one.

## Not managed yet

The authentication methods of the connector (`auth_methods`), its headers and global headers, and its OAuth2 server metadata are not arguments of this resource yet. They carry secrets, and the update cannot change the headers. Build a connector that needs them in AI Studio, then read it with the `mistral_connector` data source; its credentials can still be a `mistral_connector_credential`.

An OAuth flow, which a person completes in a browser, is out of reach of Terraform: authenticate such a connector in AI Studio. The activation of a connector for a workspace or a user has no read in the API, so Terraform could not detect a change made outside it, and is not managed either.

## Example Usage

```terraform
resource "mistral_connector" "deepwiki" {
  name        = "deepwiki"
  title       = "DeepWiki"
  description = "Explores the documentation of public code repositories."
  server      = "https://mcp.deepwiki.com/mcp"
  visibility  = "shared_workspace"
}

# An agent that calls the tools of the connector.
resource "mistral_agent" "support" {
  name  = "support"
  model = "mistral-medium-latest"
  tools = [
    { type = "connector", connector_id = mistral_connector.deepwiki.id },
  ]
}
```

## Schema

### Required

- `description` (String) What the connector does.
- `name` (String) The name of the connector, unique in the workspace: up to 64 letters, digits, underscores and dashes.
- `server` (String) The URL of the connector server, such as `https://mcp.deepwiki.com/mcp`.
- `visibility` (String) Who can use the connector: `private` (its creator only), `shared_workspace` (the members of the workspace) or `shared_org` (the members of the organization).

### Optional

- `icon_url` (String) The URL of the icon of the connector.
- `protocol` (String) `mcp` (the default) for an MCP server, or `http`. Changing it replaces the connector.
- `system_prompt` (String) A system prompt added when the model uses the tools of the connector. Changing it replaces an `http` connector.
- `title` (String) A human-readable title, up to 255 characters.

### Read-Only

- `created_at` (String) When the connector was created, in RFC 3339 format.
- `id` (String) The connector ID, a UUID. A `connector` tool of a `mistral_agent` takes it as `connector_id`.
- `modified_at` (String) When the connector was last modified, in RFC 3339 format.

## Import

In Terraform and OpenTofu 1.12 and later, an `import` block can use the resource identity:

```terraform
import {
  to = mistral_connector.deepwiki
  identity = {
    id = "0198e70f-57b0-77f6-a752-0a7f5ea2da35"
  }
}
```
