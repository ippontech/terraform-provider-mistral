# mistral_library_share (Resource)

Gives a user, a workspace or the organization access to a library, with the standard API key (`api_key`). A `Viewer` can search the library; an `Editor` can also change it.

-> **Public preview at Mistral.** The Libraries API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This resource is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

Only the owner of a library can share it, and a library cannot be shared outside the organization. The owner's own access cannot be changed or removed. To let an agent search a library created in Vibe, share it with the organization (`share_with_type = "Org"`).

The API creates a grant and changes its level with the same call. To avoid taking over a grant made outside Terraform, the create fails when the entity already has access to the library, and gives the `import` block that brings the grant under Terraform.

`level` changes in place. Another library or another entity is another grant: changing `library_id`, `share_with_type` or `share_with_id` replaces it. Destroying the resource removes the access of the entity, not the library.

## Example Usage

```terraform
resource "mistral_library" "support" {
  name = "support-docs"
}

# The support workspace can search the library.
resource "mistral_library_share" "support_workspace" {
  library_id      = mistral_library.support.id
  share_with_type = "Workspace"
  share_with_id   = "3f2e1d0c-9b8a-4f7e-8d6c-5b4a3f2e1d0c"
  level           = "Viewer"
}

# A technical writer can also change it in AI Studio.
resource "mistral_library_share" "writer" {
  library_id      = mistral_library.support.id
  share_with_type = "User"
  share_with_id   = "9a8b7c6d-5e4f-4a3b-8c2d-1e0f9a8b7c6d"
  level           = "Editor"
}
```

## Schema

### Required

- `level` (String) The access level: `Viewer` can search the library, `Editor` can also change it.
- `library_id` (String) The ID of the library. Changing it replaces the grant.
- `share_with_id` (String) The ID of the user, the workspace or the organization. Changing it replaces the grant.
- `share_with_type` (String) The kind of entity the library is shared with: `User`, `Workspace` or `Org`. Changing it replaces the grant.

### Read-Only

- `id` (String) `<library_id>:<share_with_type>:<share_with_id>`.

## Import

In Terraform 1.12 and later, an `import` block can use the resource identity:

```terraform
import {
  to = mistral_library_share.support_workspace
  identity = {
    library_id      = "0197f425-5e85-7353-b8e7-e8b974b9c613"
    share_with_type = "Workspace"
    share_with_id   = "3f2e1d0c-9b8a-4f7e-8d6c-5b4a3f2e1d0c"
  }
}
```
