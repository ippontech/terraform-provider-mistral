# mistral_agent_alias (Resource)

Points an alias of an agent at one of its versions, with the standard API key (`api_key`). A conversation started with the alias uses that version, so that an agent can change while production stays on a reviewed version.

-> **Public preview at Mistral.** The Agents API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This resource is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

The API creates and moves an alias with the same call. To avoid taking over an alias created outside Terraform, the create fails when the agent already has an alias by that name, and gives the `import` block that brings it under Terraform.

The version must exist: a `version` the agent does not have fails the apply. Destroying the resource deletes the alias, not the version.

## Example Usage

```terraform
resource "mistral_agent" "support" {
  name  = "support"
  model = "mistral-medium-latest"
}

# "staging" follows every new version of the agent.
resource "mistral_agent_alias" "staging" {
  agent_id = mistral_agent.support.id
  alias    = "staging"
  version  = mistral_agent.support.version
}

# "production" stays on a reviewed version until it is promoted here.
resource "mistral_agent_alias" "production" {
  agent_id = mistral_agent.support.id
  alias    = "production"
  version  = 3
}
```

## Schema

### Required

- `agent_id` (String) The ID of the agent. Changing it replaces the alias.
- `alias` (String) The name of the alias, unique per agent, such as `production`. Changing it replaces the alias.
- `version` (Number) The version of the agent the alias points to, such as `mistral_agent.this.version`.

### Read-Only

- `created_at` (String) When the alias was created, in RFC 3339 format.
- `id` (String) `<agent_id>:<alias>`.
- `updated_at` (String) When the alias was last pointed at a version, in RFC 3339 format.

## Import

In Terraform 1.12 and later, an `import` block can use the resource identity:

```terraform
import {
  to = mistral_agent_alias.production
  identity = {
    agent_id = "ag_0684fe0e0b98773e8000323fc71a3986"
    alias    = "production"
  }
}
```
