# mistral_model (Data Source)

Reads a model that the workspace of the standard API key (`api_key`) can use, by its ID or one of its aliases: a Mistral model, or a fine-tuned model of the organization.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

An alias such as `mistral-medium-latest` moves to a newer model when Mistral releases one, and the data source follows it on the next plan. `id` keeps the value you set; `canonical_id` is the model the alias resolves to at that plan. Set `id` to a dated model ID to keep the same model across plans.

When Mistral has planned the deprecation of the model, the read succeeds with a warning that gives the date and the model Mistral recommends instead.

## Example Usage

```terraform
# Resolve an alias to the model it points to, and fail the plan when that
# model lacks a capability the configuration relies on.
data "mistral_model" "medium" {
  id = "mistral-medium-latest"

  lifecycle {
    postcondition {
      condition     = self.capabilities.function_calling
      error_message = "The agents of this configuration call tools: their model must support function calling."
    }
  }
}

output "medium_model" {
  description = "The model the mistral-medium-latest alias resolves to."
  value       = data.mistral_model.medium.canonical_id
}
```

## Schema

### Required

- `id` (String) The model ID, such as `mistral-medium-2604`, or one of its aliases, such as `mistral-medium-latest`.

### Read-Only

- `aliases` (List of String) The aliases that resolve to this model, such as `mistral-medium-latest`.
- `archived` (Boolean) Whether a fine-tuned model is archived; null for a Mistral model.
- `base_model` (String) The model a fine-tuned model was trained from; null for a Mistral model.
- `canonical_id` (String) The ID of the model the API answered with: the same as `id`, unless `id` is an alias.
- `capabilities` (Attributes) What the model can do. (see [below for nested schema](#nestedatt--capabilities))
- `created_at` (String) When the model was created, in RFC 3339 format.
- `default_temperature` (Number) The default sampling temperature of the model.
- `deprecation` (String) When the model is deprecated, in RFC 3339 format; null for a model with no planned deprecation.
- `deprecation_replacement_model` (String) The model Mistral recommends instead of a deprecated one.
- `description` (String) The description of the model.
- `max_context_length` (Number) The context window of the model, in tokens.
- `name` (String) The display name of the model.
- `owned_by` (String) The owner of the model: `mistralai`, or the organization of a fine-tuned model.
- `type` (String) `base` for a Mistral model, `fine-tuned` for a fine-tuned model.
