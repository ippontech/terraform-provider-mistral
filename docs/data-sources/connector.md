# mistral_connector (Data Source)

Reads a connector that the standard API key (`api_key`) can use, by its name, such as a connector built in AI Studio. Its `id` is the `connector_id` of a `connector` tool of a `mistral_agent`, and of a `mistral_connector_credential`.

-> **Public preview at Mistral.** The Connectors API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

The lookup is by name, which is unique in a workspace: the ID of a connector built in AI Studio is a UUID that users do not choose. A private connector is visible only to an API key of its creator with the `Private and shared connectors` access scope.

## Example Usage

```terraform
# A connector built in AI Studio, which an agent calls as a tool.
data "mistral_connector" "github" {
  name = "github"
}

resource "mistral_agent" "triage" {
  name  = "triage"
  model = "mistral-medium-latest"
  tools = [
    { type = "connector", connector_id = data.mistral_connector.github.id },
  ]
}
```

### Required

### Read-Only

- `created_at` (String) When the connector was created, in RFC 3339 format.
- `description` (String) What the connector does.
- `id` (String) The connector ID. A `connector` tool of a `mistral_agent` takes it as `connector_id`.
- `modified_at` (String) When the connector was last modified, in RFC 3339 format.
- `protocol` (String) `mcp` or `http`.
- `server` (String) The URL of the connector server.
- `title` (String) The human-readable title of the connector.
- `visibility` (String) Who can use the connector: `private`, `shared_workspace`, `shared_org`, or `shared_global` for a connector Mistral publishes.
