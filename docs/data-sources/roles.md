# mistral_roles (Data Source)

Lists the organization and workspace roles, with their names and UUIDs, with the Admin API key (`admin_api_key`). The Admin API needs an Enterprise plan and access granted by Mistral.

-> **Public preview at Mistral.** The Admin API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

The Admin API assigns roles by name (`role_names`) or by UUID (`roles`), to invites, workspace members and user groups. It returns the roles of a member as UUIDs: this data source names them. Mistral calls this list the authoritative list of roles, and says RBAC must be enabled for the organization to read it.

These are not the roles a service account can hold. A service account takes the workspace roles that `GET /v1/service-accounts/assignable-roles` lists for its workspace, with the standard API key.

## Example Usage

```terraform
data "mistral_roles" "all" {}

output "workspace_admin_role_id" {
  description = "The UUID of the workspace_admin role, for the requests that take role UUIDs."
  value       = one([for r in data.mistral_roles.all.workspace_roles : r.id if r.name == "workspace_admin"])
}
```
