# mistral_library (Data Source)

Reads a library that the standard API key (`api_key`) can access, by its ID, such as a library built in AI Studio or Vibe, for the `library_ids` of a `document_library` tool of a `mistral_agent`.

-> **Public preview at Mistral.** The Libraries API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

A library created in Vibe has its ID in its URL (`https://chat.mistral.ai/libraries/<library_id>`). An agent can search it once it is shared with the organization, which an organization admin does in Vibe or with `mistral_library_share`.

## Example Usage

```terraform
# A library built in AI Studio, which an agent managed here searches.
data "mistral_library" "handbook" {
  id = "0197f425-5e85-7353-b8e7-e8b974b9c613"
}

resource "mistral_agent" "hr" {
  name  = "hr-assistant"
  model = "mistral-medium-latest"
  tools = [
    { type = "document_library", library_ids = [data.mistral_library.handbook.id] },
  ]
}
```
