# mistral_workspace (Data Source)

Reads an active workspace of the organization by its name, with the Admin API key (`admin_api_key`), for a `mistral_workspace_member`, a `mistral_api_key` or the workspace of a user group. The Admin API needs an Enterprise plan and access granted by Mistral.

-> **Public preview at Mistral.** The Admin API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

The lookup is by name, which Mistral keeps unique in an organization. The name matches exactly, case included. An archived workspace is not found. For a workspace that Terraform manages, refer to the `mistral_workspace` resource instead.

## Example Usage

```terraform
variable "ada_user_id" {
  description = "The ID of a user of the organization."
  type        = string
}

# A workspace created in the Admin Panel, whose members Terraform manages.
data "mistral_workspace" "production" {
  name = "Production"
}

resource "mistral_workspace_member" "ada" {
  workspace_id = data.mistral_workspace.production.id
  user_id      = var.ada_user_id
  role_names   = ["dev"]
}
```
