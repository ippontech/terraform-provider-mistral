# mistral_models (Data Source)

Lists the models that the workspace of the standard API key (`api_key`) can use: the Mistral models, and the fine-tuned models of the organization.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

Filter the list with a `for` expression, as in the example.

## Example Usage

```terraform
data "mistral_models" "all" {}

output "vision_models" {
  description = "The models of the workspace that accept images and have no planned deprecation."
  value = [
    for m in data.mistral_models.all.models : m.id
    if m.capabilities.vision && m.deprecation == null
  ]
}
```
