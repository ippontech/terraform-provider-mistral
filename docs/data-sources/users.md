# mistral_users (Data Source)

Lists the members of the organization, with the Admin API key (`admin_api_key`), for the user IDs that workspace and user group memberships take. The Admin API needs an Enterprise plan and access granted by Mistral.

-> **Public preview at Mistral.** The Admin API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

The list reads every page of the API, and holds the members only: pending invites belong to `mistral_invite`. It does not return the first and last name, which `mistral_user` reads. The roles come back as the API returns them, as on `mistral_user`.

Filter the list with a `for` expression, as in the example.

## Example Usage

```terraform
data "mistral_users" "all" {}

output "user_ids_by_email" {
  description = "The user ID of each member of the organization, by email address."
  value       = { for u in data.mistral_users.all.users : u.email => u.id if u.email != null }
}
```
