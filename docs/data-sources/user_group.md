# mistral_user_group (Data Source)

Reads a user group of the organization by its name with the Admin API key (`admin_api_key`): a group that an identity provider syncs, or one created in the Admin Panel, for the `group_id` of a `mistral_user_group_workspace` or a `mistral_user_group_member`, or the `parent_group_ids` of a `mistral_user_group`. The Admin API needs an Enterprise plan and access granted by Mistral.

-> **Public preview at Mistral.** The Admin API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

The name must match exactly, case included. Group names are not documented as unique: the read fails when no group, or more than one, has the name. The API filters the list by name in a way it does not document, so the provider compares the names itself, over every page of the list.

## Example Usage

```terraform
# A group that the identity provider syncs: Terraform reads it by name and
# gives its members access to a workspace, while the identity provider keeps
# its membership.
data "mistral_user_group" "engineering" {
  name = "Engineering"
}

resource "mistral_user_group_workspace" "engineering_production" {
  group_id     = data.mistral_user_group.engineering.id
  workspace_id = "5c6d7e8f-9a0b-4c1d-8e2f-3a4b5c6d7e8f"
  role_names   = ["user"]
}
```

## Schema

### Required

- `name` (String) The exact name of the group, case included. The read fails when no group, or more than one, has this name.

### Read-Only

- `description` (String) The description of the group.
- `externally_managed` (Boolean) Whether an identity provider manages the group, through SSO or SCIM.
- `id` (String) The user group ID, a UUID.
- `organization_role` (String) The organization role the group gives its members, such as `member`.
- `parent_group_ids` (Set of String) The IDs of the groups this group is directly nested inside.
