# mistral_agent (Data Source)

Reads an agent of the workspace of the standard API key (`api_key`) at its active version, such as an agent built in AI Studio, for a `mistral_agent_alias` or the `handoffs` of a `mistral_agent`.

-> **Public preview at Mistral.** The Agents API is in public preview: Mistral can change its fields without a deprecation period, and following them may take a new release of the provider.

~> **Not verified against the live API.** This data source is tested against a fake of the Mistral API written from Mistral's documentation. No acceptance test has run against a Mistral organization yet: please report any difference with the live API in an issue.

## Example Usage

```terraform
# An agent built in AI Studio, whose versions Terraform names.
data "mistral_agent" "studio" {
  id = "ag_0684fe0e0b98773e8000323fc71a3986"
}

resource "mistral_agent_alias" "production" {
  agent_id = data.mistral_agent.studio.id
  alias    = "production"
  version  = data.mistral_agent.studio.version
}
```
